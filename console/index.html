FIB-view · hardware

The Console

A physical control panel for the exhibits: a large focus dial, magnification and beam-current knobs, two multifunction knobs, a context knob, a stage joystick and a talk key. It is the same hardware as the TEM-view Console (in development): a USB joystick that every browser reads through the Gamepad API, with no drivers. In FIB-view the knobs follow the beam the mode uses: electrons in the SEM modes, ions in the ion image, milling, deposition and lamella modes.

No hardware? Use the keyboard

Press V in the exhibit for the on-screen panel: the same knobs, driven by the keys above or by dragging and scrolling them. It can pop out into its own window for a second screen. A standard game controller works too: sticks for the stage and the multifunction knobs, triggers for focus, bumpers for magnification and the d-pad for current and mode. The gamepad icon in the exhibit's Controls header shows the live input and lets you remap every axis and button.

Protocol

USB HID joystick, 8 axes and 16 buttons. Axes 0–1: stage joystick (absolute). Axes 2–7: focus, magnification, current, multifunction X, multifunction Y, context, as 16-bit wrapping encoder counters (4 counts per detent). Buttons 0–13: mode −/+, multifunction select, wobbler, fine/coarse, auto focus, pause, clarity, labels, narration, enlarge results, patterning, acquire, talk. Reference firmware, pin map and enclosure: the TEM-view repository.
